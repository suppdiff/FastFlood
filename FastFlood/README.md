# Fast Flood addon files

This is the **installable addon folder**. Copy this `FastFlood` directory into
`World of Warcraft/Interface/AddOns/`.

Commands: `/fastflood` (toggle settings), `/fastfloodstart` (start/stop).

One or two destinations, plus/minus on the main window. The launcher is movable
and can be shown/hidden or docked. Per-character settings survive relog; the
sending timer intentionally does not auto-restart after relog.

For full documentation, tests, licensing, and changes, see the GitHub repository's
root README.md.
